- beUI (`starc007/ui-components`): MIT-licensed animated React components consulted as the first source for any component work in BEDS. Adopted per [External component sourcing](docs/design/espaco-library/EXTERNAL-COMPONENT-SOURCING.md): logic, state model, motion and Tailwind class strings are pasted intact and become BEDS-owned; only geometry classes are swapped for BEDS proportions. No runtime import of beUI; beUI Pro blocks are unlicensed here and excluded. Each adopted component records slug, source URL and retrieval date in this file.
  - `AnimatedNumber` ← beUI `number`, `https://beui.dev/r/number/raw`, retrieved 2026-09-16, MIT. Upstream Tailwind classes, `cn` helper and easing module dropped; motion intent re-expressed with BEDS easing and tokens.
  - Text field focus ring and error nudge ← beUI `input`, `https://beui.dev/r/input/raw`, retrieved 2026-09-16, MIT. Only the state intent was adopted (soft focus ring instead of a detached outline, one nudge on a new error, settled error message). Upstream pill geometry, 44px height, Tailwind `ring-*` classes, imperative `motion.animate` calls and animated success check were not adopted: BEDS keeps its own field geometry and expresses this in CSS with `--es-focus-ring`/`--es-error-ring`.
  - `Button` / `IconButton` / `IconToggleButton` ← beUI `button-base`, `https://beui.dev/r/button-base/raw`, retrieved 2026-09-17, MIT. Motion (`whileTap` press scale, `whileHover` subtle lift via `useHoverCapable`, `motion.span` rotate spinner) and disabled idiom (`pointer-events-none` + `opacity-50`) adopted intact. Geometry swaps: `h-11 rounded-full px-5` → `min-h-8 rounded-lg px-2.5` (default), `min-h-7 rounded-md px-2.5` (compact), `min-h-10 rounded-[12px] px-3.5` (welcome — arbitrary radius, BEDS has no 12px token), `min-h-10 rounded-xl px-4` (connection). The upstream `icon` size was dropped in favor of BEDS compact 32×32 with `pointer-coarse:min-h-11 min-w-11`. `ButtonLink` / `MagneticButton` / `StatefulButton` / `MetallicButton` were not adopted.
  - `EASE_OUT` / `SPRING_PRESS` / `SPRING_SWAP` / `SPRING_PANEL` / `SPRING_LAYOUT` ← beUI `lib/ease.ts`, `https://beui.dev/r/button-base` (companion util), retrieved 2026-09-17, MIT. Mirrored to `packages/beds/src/lib/ease.ts`. `EASE_OUT` = `[0.16, 1, 0.3, 1]` matches the BEDS CSS custom property `--ease-out-expo`. Internal only, never exported.
  - `useHoverCapable` ← beUI `lib/hooks/use-hover-capable.ts`, `https://beui.dev/r/button-base` (companion util), retrieved 2026-09-17, MIT. Mirrored to `packages/beds/src/lib/hooks/use-hover-capable.ts`. Internal only, never exported.
  - `TextField` / `TextAreaField` / `SearchField` ← beUI `input`, `https://beui.dev/r/input/raw`, retrieved 2026-09-17, MIT. State intent adopted: error shake via `motion.animate` (one-shot x oscillation, reduced-motion guarded), settled error message via `motion.p` + `AnimatePresence`, soft focus ring replaces offset outline. Geometry swaps: `h-11 rounded-full` → `h-9 rounded-lg py-1 px-2.5` (settings, 36px) / `h-10 rounded-xl px-4` (connection, 40px preserved on touch) / `h-8 rounded-lg px-2.5` (search shell). Touch ergonomics inlined: `pointer-coarse:h-11 pointer-coarse:text-lg` (settings/search, 16px anti-zoom) and `pointer-coarse:h-10 pointer-coarse:text-lg` (connection, 40px preserved). The beUI animated success check and `motion.svg` path draw were not adopted: BEDS does not own a success state on fields. The beUI pill geometry, `ring-*` classes and upstream 44px default were not adopted.
  - `Checkbox` ← beUI `checkbox`, `https://beui.dev/r/checkbox/raw`, retrieved 2026-09-17, MIT. Check enter via `motion.span` + `AnimatePresence` (scale .6 → 1 in 160ms BEDS easing, reduced-motion guarded) and `whileTap` scale .92 on the visual box. Native `<input type="checkbox">` kept for form/value semantics; the beUI `motion.button role="checkbox"` was not adopted (would lose native form participation). Geometry preserved (16×16 box, `--radius-md` = 4px). Touch target grows to 44px on coarse pointer via `pointer-coarse:min-h-11`.
  - `Switch` ← beUI `switch`, `https://beui.dev/r/switch/raw`, retrieved 2026-09-17, MIT. Thumb travel via `motion.x` (0 → 14px in 180ms BEDS easing, reduced-motion guarded) instead of beUI's flexbox `justify-end`. Native `<input type="checkbox" role="switch">` kept for form/value semantics; the beUI `motion.button role="switch"` was not adopted. Geometry preserved (32×18.4 track, 16 thumb). Touch target grows to 44px on coarse pointer.
  - `SegmentedControl` ← beUI `radio`, `https://beui.dev/r/radio/raw`, retrieved 2026-09-17, MIT. **beUI modified**: the upstream `RadioGroup` / `RadioGroupItem` API was kept (radio context, motion.button role="radio") but a manual `onKeyDown` was added to the native `<input type="radio">` for ArrowLeft/Right (pill) and Arrow keys + Home/End (joined) navigation — beUI ships a bare context with no keyboard handler, which breaks `controls.spec.ts` roving and `aria-activedescendant` expectations. Native input kept over motion.button to preserve form participation and the checked-state semantics. Geometry preserved (pill 22px span / 24px container, joined 36px row). Dark-variant selection style inlined via Tailwind (text-foreground / bg-surface).
  - `Tabs` ← beUI `tabs`, `https://beui.dev/r/tabs/raw`, retrieved 2026-09-17, MIT. Activity and connection variants migrated to Tailwind + utility hover; the keyboard navigation handler (ArrowLeft/Right/Home/End, RTL mirrored) was carried over verbatim from the BEDS code since beUI's `TabsTrigger` is a bare `<button>` with no keyboard handler. The beUI `layoutId` shared-layout glide was not adopted — the active tab uses a static `bg-surface + shadow` panel instead. Settings variant deferred to a follow-up: the layout (intrinsic labels, scrollable row, bottom underline, dark variant) stays in `controls.css` until the migration lands.
  - `Dock` / `DockItem` / `DockSeparator` ← beUI `dock`, `https://beui.dev/r/dock/raw`, retrieved 2026-09-18, MIT. Pasted intact; `size` prop removed from public API (BEDS owns the 44px touch target). Uses `layoutId` for the active pill glide (`SPRING_LAYOUT`). Background uses `bg-card/80` + `backdrop-blur-xl`; no geometry overrides beyond removing the public `className`/`size` escape hatches.
  - `NumberTicker` ← beUI `number-ticker`, `https://beui.dev/r/number-ticker/raw`, retrieved 2026-09-18, MIT. Slot-machine rolling digits with staggered entry. Public `className`/`digitClassName` props removed per BEDS contract; component renders in inherited font metrics. Used for live metrics and counts — never for the fabricated ATS score, which remains static by invariant.
