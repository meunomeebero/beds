# Espaço catalog scope

Use the [portable DS map](../../../../docs/design/espaco-library/README.md) and its Governance. The older product mono/palette rules and prototype are not this catalog's visual authority.

For every BEDS UI task, automatically load and apply `better-interface`, `better-accessibility`, `better-layout`, `better-writing`, `better-typography`, `better-colors` and `better-ui`; no explicit user invocation required. Read the full entrypoints before design/code decisions and review the complete affected surface before handoff. [Interface quality](../../../../docs/design/espaco-library/INTERFACE-QUALITY.md) owns the single workflow. Report per-domain evidence and unverified checks; never approve missing coverage or substitute a static check for browser review.

Examples compose public `beds` primitives and controlled synthetic state. Run the consumer guard on each example root. Catalog navigation/chrome is documentation tooling, not evidence that an entire application passes the strict consumer contract. Do not exclude application UI to obtain a pass.

No production requests or automatic migration. Documentation-only changes do not require new screenshots; rendered changes need the scoped browser and review evidence in Governance.
